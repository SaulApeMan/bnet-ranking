# WC3 ladder in numbers / Ranking Warcraft III w liczbach

**EN** - A small static website (plain HTML, CSS and JavaScript, no backend, no forms, no external scripts) that shows
the Warcraft III in-game ladder: rankings per mode with filters (race, icon, name) and sorting, records per race,
and activity between scans. Polish and English. Open `index.html` or serve the folder with any static host
(GitHub Pages works out of the box).

**PL** - Mała statyczna strona (czysty HTML, CSS i JavaScript, bez backendu, formularzy i zewnętrznych skryptów),
która pokazuje ranking gry Warcraft III: tryby z filtrami (rasa, ikona, nazwa) i sortowaniem, rekordy per rasa
oraz aktywność między skanami. Wersja polska i angielska. Wystarczy otworzyć `index.html` albo wystawić folder na
dowolnym statycznym hostingu (GitHub Pages działa bez konfiguracji).

## Data / Dane
Public data read from the in-game Warcraft III ranking: mode, scan date, rank, display name, race, level, MMR,
wins, losses, icon. Provided as is, without warranty of accuracy (values are read from screenshots by OCR, so some
may be wrong). / Dane publiczne z rankingu gry Warcraft III, bez gwarancji poprawności (odczyt ze zrzutów ekranu,
część wartości może być błędna).

## Content / Zawartość
`*.html` pages, `assets/` (style and script), `data/site-data.js` (the data), `icons/` (player icons).
The repository contains nothing else.
